# 后端逐行注释学习版

这里放的是**学习副本**，不是生产代码。当前版本已包含“快速 / 深度 / 修复”三种模式。

> 注意：本目录的 `main_annotated.py` 覆盖配置、鉴权、限流、审查、流式、修复等核心部分，但**尚未同步**后续新增的 `storage.py`（SQLite 历史与反馈）、`folder_review.py`（zip 文件夹分析）、`review_bundles.py`（FrameworkAdapter / Bundle）以及 `main.py` 里的历史/文件夹接口。学习和排查时以生产代码为准。

- 生产代码：[main.py](../../main.py)、[services/deepseek.py](../../services/deepseek.py)
- 学习版：[main_annotated.py](main_annotated.py)、[deepseek_annotated.py](deepseek_annotated.py)

## 为什么单独放一份

如果直接给生产 `main.py` 的每一行都加 `# 注释`，代码会变得很难维护，也不符合工程习惯。

所以这里保留一份“逐行注释版”：

- 生产代码保持干净
- 学习版可以随便改、随便跑
- 你对照两份看，就能知道每一行在做什么

## 注意

- 空行、纯括号、docstring 内部没有强行加 `#`，否则会改变字符串内容。
- 这是学习副本，不要用 `uvicorn` 直接跑它；生产入口仍然是根目录的 `main.py`。
- 如果以后修改了生产代码，学习版可能滞后，以生产代码为准。
